# Rogue Path TD

Study Server의 React 프론트엔드에 게임 페이지로 통합하기 전, 독립 실행하는 타워디펜스 로그라이크 프로토타입입니다. 벽으로 몬스터의 경로를 설계하고 랜덤 유닛을 배치해 공격 구간을 만드는 것이 핵심입니다.

## 개발 및 빌드

Node.js 22 기준입니다. `mini_game` 폴더에서 실행합니다.

```bash
npm ci
npm run dev
```

```bash
npm run build
```

현재 프로토타입은 React 19, TypeScript, Vite 8로 구성되어 있습니다. 독립 실행 버전에는 React Router와 서버 API 연동이 없습니다. 기존 서비스에 통합할 때 서비스의 라우터와 인증/API 모듈에 연결해야 합니다.

## 현재 구현

- 화면은 왼쪽 시너지와 하단 로그, 가운데 전투 HUD·게임판·업그레이드 현황·상세정보·창고, 오른쪽 플레이어 정보·피해량·커맨드의 3열 UI로 구성됩니다. 창고는 커맨드 바로 왼쪽에 배치되고 슬롯은 화면 폭에 따라 맵 셀과 같은 크기로 함께 조절됩니다. 좁은 화면에서는 게임판을 먼저 보여주는 세로 배치로 전환됩니다.
- 커맨드의 `A` 또는 디버그 버튼으로 접근 번호를 입력한 뒤 테스트 패널을 열 수 있습니다. 빈 맵 초기화, 시작점·골 지점·벽 편집, 골드·플레이어 레벨·타이머 설정, 지정 유닛의 창고 추가, 유형·보스 여부·수량을 지정한 몬스터 즉시 소환과 소환 몬스터 초기화를 지원합니다. 경로를 완전히 차단하는 맵 편집은 적용되지 않습니다. 클라이언트 코드의 접근 번호는 개발 편의 기능이며 보안 경계로 사용하지 않습니다.
- 데스크톱에서는 세로 스크롤 없이 한 화면에 들어옵니다. 상단 HUD에는 스테이지, 남은 시간, 최고 완주 횟수, 남은 몬스터와 출현 비율을 표시하며 남은 시간 10초 이하와 위험한 완주 횟수는 빨간색으로 강조합니다.
- 3×3 커맨드는 유닛·업그레이드·경험치 구매, 경로 표시, 배속, 일시정지/재개, 웨이브 시작, 새 게임으로 구성됩니다. 새 게임은 확인 창을 거쳐 초기화합니다. 명령이나 유닛에 마우스를 올리거나 키보드 포커스를 두면 설명과 실제 적용 능력치가 툴팁으로 표시됩니다.
- 맵 바로 아래에는 9종 유닛의 현재 공격력 업그레이드 수치를 한 줄로 표시합니다. 게임 로그는 왼쪽 하단에서 독립적으로 스크롤되며, 중앙 하단에는 유닛 상세정보와 창고를 배치합니다.
- 맵이나 창고의 유닛을 선택하면 상세정보 영역에 현재 등급, 직업·특화, 공격력·공격속도·사거리와 고유 효과가 표시됩니다. 현재 등급이 반영된 기본 수치는 흰색, 구매 업그레이드는 노란색, 적용 중인 시너지는 초록색으로 구분합니다.
- 우측 상단 데미지 랭킹은 한 번에 5개 유닛만 표시하며 버튼으로 TOP 5·BOTTOM 5를 전환합니다. 우측 하단은 레벨·경험치, LIFE·GOLD, 배치·벽 현황과 정사각형 커맨드 순서로 구성됩니다.
- 준비 단계에 맵 셀을 클릭하면 상하좌우에 같은 크기의 컨텍스트 버튼이 표시됩니다. 빈 칸은 벽 설치, 빈 벽은 벽 제거·유닛 배치, 유닛이 있는 벽은 회수·판매·승급을 제공합니다. 출발점·도착점·영구벽에는 메뉴가 표시되지 않습니다.
- 창고 유닛을 클릭하면 위쪽 배치, 왼쪽 승급, 오른쪽 판매 메뉴가 표시됩니다. 배치를 선택하면 가능한 맵 벽이 금색으로 점멸하고, 빈 벽에서 유닛 배치를 선택하면 고를 수 있는 창고 유닛이 금색으로 점멸합니다.
- 선택한 유닛을 다른 맵 유닛이나 창고 유닛 위로 옮기면 두 유닛의 자리를 교환합니다. 맵 유닛을 빈 창고 칸으로 옮기거나 창고 유닛을 빈 벽에 배치하는 직접 이동도 지원합니다.
- 열려 있는 맵 셀이나 창고 슬롯을 다시 클릭하면 선택과 컨텍스트 메뉴가 해제됩니다. 맵에 배치된 유닛의 승급을 실행하면 결과 유닛이 창고로 이동하지 않고 선택했던 맵 위치에서 바로 상위 등급으로 바뀝니다.

- 7행 × 20열 맵. 시작점(S)과 도착점(G)을 무작위로 정하고 자연벽 10개, 영구벽 2~3개를 배치합니다.
- 상하좌우 BFS 최단경로를 사용합니다. 벽 설치로 S→G 경로가 막히면 설치를 거부하고, 경로 표시를 꺼도 경로 계산은 유지합니다.
- 플레이어 벽은 최대 18개 설치할 수 있습니다. 새 벽은 해당 웨이브 시작 전 철거 시 전액, 이후 철거 시 절반을 환불합니다. 자연벽은 비용을 내고 파괴할 수 있고 영구벽은 파괴할 수 없습니다.
- 플레이어 벽과 자연벽에 유닛을 한 칸당 하나씩 배치합니다. 준비 단계에는 창고 회수와 벽 사이 이동이 가능합니다.
- 9종 유닛(전사·마법사·사수 각 3종), 인간·육지마수·조류형마수 적, 유닛 특화별 피해 배율을 구현했습니다.
- 상점의 두 버튼 중 유닛 구매를 누르면 9종 중 한 종류를 무작위로 얻어 20칸 창고에 보관합니다. 같은 종류·등급의 유닛 3개를 수동 합성해 최대 3등급까지 승급할 수 있습니다.
- 플레이어는 1레벨에 유닛 3기를 배치할 수 있고, 레벨이 오를 때마다 배치 한도가 1기씩 늘어나 최대 10레벨·12기까지 배치할 수 있습니다. 준비 단계에 20G로 경험치 10을 구매하며, 다음 레벨 요구 경험치는 20부터 레벨마다 10씩 증가합니다.
- 창고 유닛은 준비 단계에 판매할 수 있습니다. 판매가는 1성 10G, 2성 35G, 3성 110G로, 합성 후 판매하면 재료를 개별 판매하는 것보다 약간 더 받습니다.
- 업그레이드 구매는 개별 유닛 9종 × +1~+3업(27개), 직업 3종 × +1~+3업(9개), 특화 3종 × +1~+3업(9개), 모든 유닛 +1~+2업(2개) 중 하나를 추첨합니다. 기존 유닛과 앞으로 얻는 유닛 모두에 적용됩니다.
- 맵 아래 업그레이드 현황은 9종 유닛별 현재 총 업그레이드를 한 줄로 표시합니다.
- 배치된 유닛의 직업·특화별 수로 3/6/9/12/15명 시너지를 적용하고, 현재 효과를 HUD에 표시합니다. 창고 유닛은 인원수에 포함하지 않습니다.
- 시너지 HUD는 각 직업·특화의 현재 인원과 다음 발동 기준을 표시하고 5단계 효과 수치를 모두 미리 보여줍니다. 아직 발동하지 않은 수치는 회색이며 현재 적용 중인 단계 하나를 흰색으로 강조합니다.
- 투사체가 목표에 도착하면 피해를 적용합니다. 범위 공격은 맞은 적마다 상성을 계산하고, 산탄총은 각 적과 사수 사이 거리로 피해가 감소합니다. 쌍검사 2타, 화염술사의 확률형 범위 공격, 둔화·마비와 공통 상태이상 면역, 저격 즉사 효과도 구현했습니다.
- 제한시간 동안 몬스터는 HP를 유지하며 S→G 경로를 반복합니다. 몬스터 하나가 5회 완주하면 게임오버이고, 시간이 끝나면 생존 몬스터 수만큼 Life를 차감합니다.
- 5·10·15·20·25·30스테이지는 일반 몬스터 대신 보스 1마리만 등장합니다. 31~35스테이지는 적의 수와 체력이 크게 증가하는 강화 일반 웨이브이며, 이후 `FINAL STAGE`에서는 세 형태로 변환하는 최종 보스를 상대합니다. 보스는 5회 완주 제한이 없지만 웨이브 제한시간 안에 처치하지 못하면 즉시 게임오버입니다. 저격병의 즉사는 보스에게 적용되지 않고 추가 피해로 바뀝니다.
- 웨이브 중 탭이 숨겨지거나 브라우저 창이 포커스를 잃으면 자동으로 일시정지합니다. 다시 화면으로 돌아온 뒤 `웨이브 재개` 버튼을 누르면 제한시간·몬스터 이동·스폰·공격이 이어집니다. 백그라운드에 있던 시간은 웨이브 시간에 포함하지 않습니다.
- `1배속`/`2배속` 버튼으로 웨이브 진행 속도를 바꿀 수 있습니다. 제한시간, 스폰, 이동, 공격 대기시간, 투사체와 상태이상은 같은 게임 시간을 사용합니다. 일시정지 중에는 게임 시간이 흐르지 않습니다.
- 스테이지 종료 후 배치 유닛별 실제 피해량, 전체 피해에서 차지한 비율과 총 피해량을 표시합니다. 범위 피해와 저격 즉사 피해도 해당 공격 유닛에 합산합니다.
- 같은 직업의 서로 다른 3성 유닛 3종을 모두 배치하면 스테이지 시작 20초 후부터 직업 필살기를 판정합니다. 성공 확률은 25%이며 실패 시 15초, 성공 시 60초 뒤 다시 판정합니다. 필살기는 세 유닛의 성급·업그레이드 적용 공격력 합계에 전사·마법사 3배, 사수 1.75배를 적용해 맵 전체에 고정 피해로 주며, 노업 3성 조합은 직업별 약 500 피해로 맞춥니다. 최종 보스에게 빛을 잃은 유닛의 기여분은 50% 감소합니다.
- 게임오버 및 마지막 웨이브 클리어 후에는 새 웨이브를 시작할 수 없습니다. 새 게임은 `새 맵` 버튼으로 시작합니다.

## 현재 테스트 값

수치는 `src/games/rogueTd/constants.ts`에서 관리합니다. 현재 시작 골드 180G, 시작 Life 10, 35개 스테이지와 `FINAL STAGE`, 일반 웨이브와 일반 보스 웨이브 제한시간은 모두 90초로 구성됩니다. 최종 보스는 네 페이즈가 제한시간 360초를 공유하며 빛 흡수·방출과 형태 전환 중에는 타이머가 멈춥니다. 일반 스테이지의 적 수는 25마리에서 시작해 진행에 따라 증가합니다. 인간·육지·조류형이 섞여 나오고 주력 유형은 스테이지마다 순환합니다. 플레이어 벽 설치는 10G, 자연벽 파괴는 20G, 무작위 유닛 구매는 20G, 업그레이드 구매는 30G입니다. 플레이어 벽을 철거하면 규칙에 따라 설치 비용의 50% 또는 100%를 돌려받습니다.

일반 적 처치 보상은 2G이며 일반 웨이브를 모두 처치하면 추가로 30G를 받습니다. 제한시간 종료 시 생존 적이 남아 있어도 게임이 계속된다면 추가 보상은 10G입니다. 보스는 처치 시 10G, 클리어 시 추가 60/80/100/120/140/160G를 받습니다. 보스를 시간 안에 처치하지 못하면 게임오버이며 클리어 보상은 없습니다. 1스테이지 적을 모두 처치하면 총 80G, 첫 보스를 처치하면 총 70G입니다.

1차 유닛·적 밸런스는 역할 차이를 확인하기 위한 값입니다. 같은 등급·시너지·업그레이드가 없을 때 검사는 근거리 단일 공격, 쌍검사는 더 짧은 사거리의 2타, 마검사와 산탄총병은 광역 공격, 화염술사는 30% 확률로 광역 공격, 얼음술사와 번개술사는 상태이상, 소총수는 안정적인 원거리 공격, 저격병은 긴 사거리의 느린 단발 공격에 초점을 둡니다. 둔화·마비 기본 발동 확률은 각각 10%, 저격 즉사는 5%입니다.

일반 적의 1스테이지 기준 능력치는 인간 HP 40·속도 1.4, 육지마수 HP 55·속도 1.15, 조류형마수 HP 30·속도 1.7입니다. 일반 적 HP는 스테이지가 하나 증가할 때마다 기본값의 16%씩 증가하고 속도는 유지됩니다. 보스 HP는 첫 보스 300을 기준으로 다음 보스마다 1.75배이며, 이동 속도는 해당 유형의 일반 적과 같습니다. 배치 한도와 플레이어 성장에 맞춘 첫 조정값이며, 피해량 통계와 실제 클리어율을 보면서 다시 조정합니다.

업그레이드는 현재 피해량만 올립니다. +1업당 해당 유닛의 기본 피해량 5%를 추가하며, 준비 단계에서 골드가 허용하는 만큼 구매할 수 있습니다. 추첨 범위의 총 확률은 개별 유닛 60%, 직업 전체 25%, 특화 전체 12%, 모든 유닛 3%입니다. 범위 내 대상은 균등 추첨하고, +1/+2/+3업의 조건부 확률은 60%/30%/10%입니다. 모든 유닛 범위에서는 +1/+2업을 80%/20%로 추첨합니다. 이 값은 플레이 테스트용이며 `src/games/rogueTd/upgrades.ts`와 상수 파일에서 조정할 수 있습니다.

전투 수치는 1차 가정이며 플레이 결과에 따라 조정합니다.

시너지도 테스트 값입니다. 최대 배치 수에 맞춰 3/6/9/12명 단계로 구성됩니다. 전사는 공격속도 +5/10/15/20%, 마법사는 특수효과 발동 확률 +5/10/15/20%p, 사수는 사거리 +0.15/0.30/0.45/0.60칸입니다. 밸런스 유닛은 모든 적 대상 피해 +3/6/9/12%, 육지 특화와 조류 특화는 해당 유형 대상 피해 +5/10/15/20%입니다. 시너지 수치는 `src/games/rogueTd/synergies.ts`에서 조정합니다.

## 확인이 필요한 부분

- 시너지와 업그레이드의 실제 밸런스는 플레이 테스트가 필요합니다.
- 기존 서비스 통합과 브라우저 플레이 검증은 별도로 필요합니다.

## 이미지 자산 관리

- 게임에서 직접 불러오는 최적화 이미지와 스프라이트 시트는 `src/images/`에 있습니다.
- `art_sources/images/`는 고해상도 원본과 제작 중간본을 보관하는 로컬 작업 폴더이며 저장소 용량을 줄이기 위해 Git에서 제외합니다.
- `scripts/`의 Python 스크립트는 로컬 원본에서 일부 몬스터와 보스 스프라이트를 다시 생성할 때 사용합니다.
